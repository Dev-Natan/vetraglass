Antes de realizar qualquer ação, entenda o contexto e instrução recente do usuário, comando mais recente enviado por ele: Reestruturação do Módulo "Meus Preços": Precificação por Variação (Linhas de Preço) Objetivo: Mudar o modelo de precificação para suportar múltiplos preços para o mesmo produto base, dependendo das especificações (ex: tipo de vidro, espessura, cor). Exemplo: O produto "Janela" terá uma linha para "Vidro 6mm Incolor" (R$ 1240/m²) e outra para "Vidro 6mm Verde" (R$ 1350/m²). Requisitos de Dados (Schema): 1. Manter a tabela `products` para o produto base (Nome, Descrição). 2. Criar/Atualizar a tabela `product_price_lines` (ou `variations`) com: - `id`: Chave primária. - `product_id`: FK para `products`. - `description`: Descrição específica da variação (ex: "Vidro Incolor 6mm"). - `attributes`: Campo JSON (opcional, para filtros futuros) ou colunas específicas (ex: `glass_type`, `thickness`). - `price`: Valor da linha (ex: 1240.00). - `unit`: Unidade de medida (ex: 'm²', 'un', 'par'). - `is_active`: Booleano. Funcionalidades da UI (Frontend): 1. **Cadastro de Produto com Linhas de Preço:** - Ao criar/editar um produto, exibir uma seção "Linhas de Preço" ou "Variações". - Um botão "Adicionar Nova Variação" que abre um mini-formulário ou linha inline. - Campos da linha: - Descrição da Variação (ex: "Vidro Incolor 6mm"). - Espessura (se aplicável, ex: 6mm, 8mm). - Tipo (ex: Incolor, Verde, Fume). - Preço Unitário. - Unidade de Medida (m², unidade, etc.). - Permitir adicionar múltiplas linhas para o mesmo produto. 2. **Listagem de Preços por Produto:** - Na tela "Meus Preços", ao clicar em um produto, exibir uma lista das variações cadastradas com seus respectivos preços. - Permitir editar/excluir linhas individuais sem apagar o produto base. 3. **Integração com Orçamentos (Seleção Inteligente):** - Ao adicionar um item no orçamento: - Passo 1: Selecionar o Produto Base. - Passo 2: Se o produto tiver múltiplas variações, exibir um **segundo seletor** ou um modal para escolher a variação específica (ex: "Qual vidro?"). - Passo 3: Ao selecionar a variação, o sistema preenche automaticamente o `preço_unitário` e a `unidade` daquela linha específica. - Se o produto tiver apenas uma variação (ou nenhuma), usar o preço padrão (se houver) ou solicitar a criação da primeira variação. 4. **Cálculo de Margem por Variação:** - Se possível, permitir definir o `custo` por linha de preço também, para calcular a margem exata daquela configuração específica. Ações Técnicas para a IA: 1. Criar a estrutura de dados `product_price_lines` com os campos descritos. 2. Refatorar o formulário de produto para aceitar uma lista de variações (array de objetos) no momento do salvamento. 3. Criar o componente de seleção no orçamento que lida com a lógica "Produto -> Variação -> Preço". 4. Garantir que o cálculo do total do orçamento use o preço da variação selecionada. Exemplo de Uso Esperado: - Usuário cadastra "Janela Deslizante". - Adiciona linha 1: "Vidro 6mm Incolor", Preço: 1240, Unidade: m². - Adiciona linha 2: "Vidro 6mm Verde", Preço: 1350, Unidade: m². - No orçamento, seleciona "Janela Deslizante" -> Escolhe "Vidro 6mm Verde" -> O sistema preenche R$ 1350/m². Objetivo Final: Eliminar a necessidade de criar produtos duplicados (ex: "Janela Incolor", "Janela Verde") e permitir uma gestão de preços granular e precisa baseada nas especificações técnicas do pedido.
